# Third-party assets

These files are included as permissively licensed game art. The game uses cropped copies of the original sprites where noted.

## Lever sprites

- Files: `lever-down.png`, `lever-up.png`
- Source: [Strange underground Platformer](https://opengameart.org/content/strange-underground-platformer), `Sorted/InteractableItems/GoldLever.png`
- Author: UnholyMoly
- License: CC0 1.0 Universal
- The source pack includes the lever as a three-frame 16×16 spritesheet. The first and third frames were cropped for the two visible lever states used by the game.

## Stone wall texture

- File: `stone-wall.png`
- Source: [Seamless Wall](https://opengameart.org/content/seamless-wall), `wall128x128.png`
- Author: GrumpyDiamond
- License: CC0 1.0 Universal
- The texture is used as the sliding stone barrier in Level 1.
