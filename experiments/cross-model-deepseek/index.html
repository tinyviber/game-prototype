cross-model · deepseek — Six Orthogonal Puzzle Directions

A blind divergent exploration for a persistent-protagonist programming puzzle game. Six archetypes, six causal engines, six interfaces. Every demo is a standalone single-file HTML prototype — open it, press Run, watch the world debug itself.

DEMO 01

The Gravity Amendment

Vector A · Environmental Law Mutation

Rewrite which way "down" is. Water re-floods, the boulder re-rolls, and your own body is the second key to the gate.

causal model: one law → whole environment re-simulates · interface: timed law-list
 DEMO 02

March the Oaf

Vector B · Asynchronous Delegation

A blind stone golem marches the tape you queue: walk, push, smash, wait. Wind it up, step back, watch it bonk.

causal model: queue → autonomous executor → irreversible world · interface: command queue
 DEMO 03

Echo Canyon

Vector C · Temporal & State Echoes

Write a 10-frame song; your own echo holds the bridge and the door forever — then dash in time with your ghost.

causal model: recording → infinite replay → self-cooperation across time · interface: 10-frame tape
 DEMO 04

The Whispering Grotto

Vector D · Sensor–Actuator Networks

Herds invisible motes by sound. Deploy listening stones, lure bells and hum pipes; wire IF-HOT-THEN rules in the dark.

causal model: sensor read → threshold rule → actuator → hidden-state cascade · interface: deployment + rules
 DEMO 05

The Dam That Breathes

Vector E · Emergent Flux & Equilibrium

The river pulses forever. Tune the sluice rules or drown the valley; the wheel gate opens only in the band, the ford only at low tide.

causal model: continuous inflow → level → outflow → wheel streak · interface: reactive threshold rules
 DEMO 06

Mimic Moss

Vector F · State Metamorphosis & Wiring

Grow wires of light. Red first, then blue — the flower opens only if your two branches are the right lengths. Trim the sprouts.

causal model: topology → 1-hop signal → path-length delay → color flip · interface: spatial wiring
All six are zero-dependency, single-file prototypes (vanilla HTML/JS/CSS + inline SVG). The shared protagonist "Pip" appears in every world. See IDEAS.md, DIRECTIONS.md, DISCERNMENT.md.
